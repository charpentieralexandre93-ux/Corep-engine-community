# Frontière de release publique — Community v6.4.1

Community est l'édition **publique** Apache-2.0. Elle contient uniquement le périmètre SA / SA-CCR et les utilitaires publics de bootstrap, santé, GUI et intégrité de release.

## Règle de frontière

Sont interdits dans l'archive Community : moteurs IRB, CVA, SFT, liquidité, market risk, titrisation, grands risques, crypto-assets, DPM/XBRL officiel, gouvernance de soumission et EULA propriétaire.

La publication publique reste conditionnée à :

1. ZIP source reproductible ;
2. wheel public vérifié ;
3. manifeste SHA-256 vérifié ;
4. CI verte sur le tag distribué ;
5. absence de fichier propriétaire ou moteur Enterprise.
